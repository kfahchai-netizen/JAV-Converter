Welcome to JAV Conversion!
Turn up your volume as this application contains sound!
Before running the application do remember to install Tkinter and Pygame by following the instruction below:

Step 1: Open command prompt 
Press Window + R to open the Run dialog
Then in the text box type: cmd then press enter

Step 2:
Type the following into the command prompt:
	pip install tk
then press enter

Step 3:
Type the following into the command prompt:
	pip install pygame
then press enter

Once that's done, you may exit the command prompt and open the Python file named: Main_module

Enjoy the application!
